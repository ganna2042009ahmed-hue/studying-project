# Description  
This project is a Chrome extension that allows you to customize the appearance of any website you visit. It lets you change the background color to light blue, change the text color to blue, and increase the font size to 22px to make the text bigger and easier to read. You can also reset all changes and return the website to its original

# How to try  
1 Download the Extension:
Open the Studying Project https://github.com/ganna2042009ahmed-hue/studying-project/releases/tag/v1

2. Download the ZIP File:
Scroll down to Assets and click the ZIP file to download it.

3. Extract the ZIP File:
Find the downloaded ZIP file and extract it.

4. Open Chrome Extensions:
Open Google Chrome and go to:
chrome://extensions

5. Enable Developer Mode:
Turn on Developer mode using the switch in the top-right corner.

6. Load the Extension:
Click Load unpacked and select the extracted project folder.

7. You're Done!
The extension is now installed and ready to use
